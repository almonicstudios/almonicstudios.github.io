# almonicstudios.github.io

Website for Almonic Studios, served by GitHub Pages at https://almonicstudios.github.io

- `/` : studio home, one card per app
- `/<app>/` : help and contact page for each app (the App Store "Support URL")
- `/<app>/privacy.html` : privacy policy for each app (the App Store "Privacy Policy URL")
- `/app-ads.txt` : AdMob authorised sellers file. It must stay at the site root, and this domain must be the "Marketing URL" / developer website in App Store Connect.

Adding a new app: copy `maumau/` to `<app>/`, change the text and icon, and add a card to `index.html`.
